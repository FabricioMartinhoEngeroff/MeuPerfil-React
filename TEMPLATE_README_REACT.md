## 📋 O que tem implementado

- [x] Autenticação com Context API
- [x] Gerenciamento de estado com Zustand
- [x] Roteamento com React Router v6
- [x] Consumo de API REST
- [x] Testes unitários (coverage 70%+)
- [x] TypeScript strict mode
- [x] Loading states e error boundaries
- [x] Lazy loading de rotas

## 🛠️ Stack

- React 18.2
- TypeScript 5.0
- Vite (build tool)
- React Router v6
- Zustand (state management)
- React Query (data fetching)
- Vitest + React Testing Library
- CSS Modules / Styled Components

## 📦 Instalação

```bash
# Clone
git clone https://github.com/seu-usuario/seu-projeto.git

# Instale dependências
npm install

# Configure variáveis de ambiente
cp .env.example .env
# Edite o .env com suas credenciais

# Execute em dev
npm run dev
```

Acesse: http://localhost:5173

## 🧪 Testes

```bash
# Rodar todos os testes
npm run test

# Coverage
npm run test:coverage

# Watch mode
npm run test:watch
```
